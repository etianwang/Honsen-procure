## Non-negotiable implementation rules

1. Desktop is Tauri 2 + React + TypeScript + SQLite; cloud is TypeScript HTTPS API + PostgreSQL. Desktop never connects to PostgreSQL.
2. Every application launch requires account password plus local CAPTCHA; enabled cached accounts may sign in offline for at most 24 hours.
3. React is untrusted. Rust/Tauri and server independently authorize every protected mutation.
4. SQLite mutation plus outbox event is one transaction. HTTPS Push/Pull is authoritative; WebSocket is only a Pull hint.
5. Saved order lines snapshot all catalog/supplier/price/tax data. Catalog changes never rewrite historic orders.
6. Use UUIDs, soft deletion, versions, idempotency and explicit conflicts. Never silently overwrite conflicts.
7. Comments are immutable after sending. Closed orders are immutable. Sent supplier orders require cancellation/revision, never direct edit.
8. Do not invent Toolbox app identity or release settings. Internal automatic updates still require the exact Toolbox/Runner contract.
