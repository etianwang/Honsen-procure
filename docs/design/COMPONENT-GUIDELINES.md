# Component Guidelines

## 所有权与接口

共享组件由单一负责人维护，业务页面不得复制另一套控件样式。优先 React、原生语义元素和已有 Ant Design 依赖。展示组件不访问任意 SQL，不承担价格计算、授权或工作流迁移。

组件使用受控值、明确的变更回调和结构化状态。FormField 连接固定 label、输入 id、帮助文字和字段错误；错误通过 aria-describedby 关联。业务服务保留失败输入，提交期间阻止重复写入。

## 控件契约

- Button：明确主次、loading、disabled；禁用原因在邻近位置可见。
- Dialog/Drawer：有可访问标题，进入后聚焦，限制焦点在模态框内；Esc 关闭非提交状态，退出恢复触发焦点；未保存内容需明确处理。
- SearchSelect：受控 selected value、异步 query/page、loading/error/empty、下一页状态；防抖及过期请求丢弃。方向键导航、Enter 选择、Esc 关闭；不能预加载全目录并在前端全量过滤。
- Table：稳定行标识、表头、金额币种、状态文字和操作列；服务端或 SQLite 分页保留筛选；宽表允许明确的表格滚动，不制造整页横向溢出。
- InlineFeedback：就近显示处理中、成功、失败；异步结果采用合适的 live region。Toast 仅用于无需持续参考的辅助反馈。
- Stepper：明确当前步骤、完成状态及下一步，普通校验失败保留输入；步骤错误不得只放在页面底部。
- EmptyState/Loading：区分无记录、筛选无结果、加载和失败；失败包含重试入口。

## 安全与离线

UI 权限仅决定可见性，可信 Rust/API 授权必须保留。离线普通业务写入、outbox 原子性、正式编号、冻结快照和付款冲销不可因设计调整改变。在线授权管理必须明确网络限制。

## 本地化

全部可见文案和动态错误包含中文、法语、英语消息键。组件不拼接翻译片段。切换语言保留路由和输入；金额和日期按 locale 展示。
