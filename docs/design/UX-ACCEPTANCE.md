# UX Acceptance

## 证据状态

此文件定义验收规则，不宣称已有通过结果。未执行项记录 NOT_RUN，失败记录 FAIL，只有实际观察及可复现证据支持 PASS。

## 覆盖记录

每个页面记录导航入口、角色、在线/离线、语言、控件、关键操作、预期/实际、严重程度、代码修复状态及截图/测试位置。覆盖登录/CAPTCHA、首页、材料/分类/单位、供应商/报价、采购创建/历史/审批、执行/RFQ/SPO/HPA/OPA、付款/冲销/收货、PDF/导出/打印、基础资料、账号授权、同步冲突、设置以及所有弹窗和向导。

控件逐项确认固定标签、必填、示例、字段错误、即时反馈、加载、成功、失败、禁用原因、键盘顺序和恢复返回。保存失败不清空输入；查询失败不显示成无数据。

## 必须实际执行

- 中文、法语、英语分别验证长标签、按钮、动态校验、空状态、错误、日期和金额。
- Windows 原生鼠标键盘验证 1280×720、1366×768、1920×1080；DPI 100%、125%，环境支持时 150%。缺少环境需记录具体阻塞，不能以浏览器 viewport 替代 DPI。
- 每页执行主要业务操作，包括成功、校验失败和恢复；Tab、Enter、Esc 和方向键适用于对应控件。
- Playwright DOM 回归覆盖实际受影响入口及可访问控件，收集 console；Mock 不能替代原生业务验收。
- 使用隔离合成数据检查数万材料和历史记录的分页、搜索请求数、防抖、响应耗时及 DOM 数量，记录数据规模与环境，不只报告小样本速度。
- 执行格式、lint、strict typecheck、单元、构建及受影响 Rust/API/集成回归；未执行项说明影响。

## 数据边界

禁止通过验收修改真实云端业务、历史订单、正式号、付款冲销或冻结快照。需要写入的业务路径使用明确隔离测试环境；任何截图不得暴露密码、令牌或连接串。

完成报告应提供逐页矩阵、问题严重程度和状态、前后截图、提交、三语/DPI/性能/回归结果及 BLOCKER、DEFERRED、WARNING。设计文档存在不构成验收通过。
