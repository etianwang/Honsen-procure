# HONSEN Modern Industrial

## 定位

面向 Windows 11 采购人员的专业、紧凑、清晰、高效桌面工作台。保留 HONSEN 深绿色导航，内容以表格、清晰标签和就近反馈为主，避免巨大卡片、按钮和装饰留白。

## 信息层级

导航承担模块切换；顶部工具栏承担授权范围、语言、同步摘要及用户菜单；内容区承担标题、筛选、主要动作、数据和详情。技术同步细节进入可展开的状态区域，不占据主要工作区域。

每个页面保留一个明确主要动作。业务编号优先，UUID 仅作为辅助信息；无正式编号的草稿显示合法临时编号或“草稿”。财务数值始终显示币种，界面不得重新计算或改写历史快照。

## 可读性

正文 13–14px，以系统中文和拉丁字体回退，行高约 1.5。标题适度增加层级。间距基于 4px，控件圆角 6px、面板 8px；通过对齐、边界和密度组织信息，不以阴影建立层级。

所有标签持续可见；颜色必须配合文字或图标。法语长文案允许换行，不能隐藏关键信息。设计调整不改变权限、采购状态、价格或同步规则。

## 实施与证据

本规范是目标，不代表所有页面已完成改造。逐页审计、真实 Windows 和三语验收按 [UX-ACCEPTANCE.md](UX-ACCEPTANCE.md) 记录；共享规则按 [COMPONENT-GUIDELINES.md](COMPONENT-GUIDELINES.md) 实施。
