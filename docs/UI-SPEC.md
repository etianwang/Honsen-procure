# UI Specification

## Product shell

## Approved visual direction

Use the approved Chinese desktop-workbench direction as the product visual baseline: restrained HONSEN green accent, light/dark adaptive surfaces, compact left navigation, persistent top status bar, data-dense tables, small rounded controls and explicit text-plus-color statuses. The visual drafts are stored in the task visualization workspace; `honsen-all-chinese-screens.html` is the full-screen inventory.

Desktop-first Windows layout: left navigation, top global status bar, main work area and a collapsible right activity panel. The top bar always shows signed-in user/photo, current roles, sync state, pending attachment count, notification bell, language picker (`中文` / `Français` / `English`) and lock action. Use one active UI language at a time, with complete localized labels rather than tripling labels in every control. Use visible text plus icon/color for state; all actions are keyboard reachable.

Urgency is low/green, normal/blue and high/yellow. External-language text is visually larger than Chinese in printed/PDF documents. The application supports Chinese+French and Chinese+English per order and per print.

## Navigation

Primary navigation: Home, Orders, Approval, RFQs, Receiving, Materials, Suppliers, Prices, Master Data, Notifications, Export. Administration adds Users, Sync/Conflicts, Backup/Restore and Settings. Hide unavailable write actions rather than entire read screens; the trusted boundary remains authoritative.

## Responsive and accessibility behavior

The primary target is desktop widths. At narrower widths, line tables retain essential columns and open a row detail drawer for secondary values; actions remain visible in an overflow menu with text labels. Dialogs trap focus, return focus on close, show validation beside its control and never rely on color alone.
