## Implementation boundary

- `CANONICAL_UPDATE_URL` is the approved GitHub stable API. The typed parser requires explicit false draft/prerelease, numeric v-tag, one exact version-matched Setup.exe asset, exact same-repository HTTPS release URL and lowercase GitHub sha256 digest. Duplicate relevant JSON fields, ambiguous setups, missing/invalid digest/size, invalid versions and reflected/query-bearing/foreign URLs reject with static errors. Normal unrelated GitHub fields and auxiliary non-installer assets are allowed. Metadata is capped at1MiB, assets at256, selected installer size must be positive and at most1GiB, aligned with the WinHTTP implementation.
- Versions are compared as three/four ASCII integer components, padding the fourth component with zero; signs, suffixes, whitespace and u32 overflow reject. There is no lexical ordering or floating-point version calculation.
- Private preferences use only schemaVersion1 and skippedVersion at `%LOCALAPPDATA%/Honsen Program/UpdatePreferences/honsen.procure.json`. Only the exact validated version string is stored; no token, URL, business data or permanent-disable flag. Missing settings return None without creating directories. Malformed/oversized/unknown-schema/unknown-field settings or I/O errors fail explicitly; caller policy must warn/default-check rather than treating them as a permanent skip.
- On Windows every existing ancestor is opened with OPEN_REPARSE_POINT/BACKUP_SEMANTICS and verified as a normal directory. Directory handles omit FILE_SHARE_DELETE until the operation finishes, preventing parent rename/reparse swaps. Destination directory/file symlinks and reparse points reject. A unique create_new temporary file is fully written/synced, then replaced using MoveFileExW with REPLACE_EXISTING/WRITE_THROUGH; failures preserve the prior file and clean only the owned temporary path. No direct write truncates existing preferences.
- Filesystem tests use injected private test roots under repository `.cache/update-launch-tests`, not the real preference path or C-drive temporary locations. No global LOCALAPPDATA mutation, user/group changes, production settings or external service access is needed. Public preference operations return UnsupportedPlatform outside Windows.
